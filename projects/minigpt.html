Transformer Pretraining Evals From scratch

MiniGPT

I trained my own language model from zero. No one else’s weights! It started as random numbers, read 16 billion tokens on one GPU, and came out able to answer science questions. Everything on this page is from its real training log.

Starting from nothing

I call it the 350M, but the exact count is 369,148,928 parameters. Every one of them started as a random number. I even trained my own tokenizer (the thing that chops text into pieces) before the model saw a single word.

Then it started reading. The reading list is FineWeb-Edu, a public set of educational web pages. 16 billion tokens went through it in about 4 days on the one GPU in my PC, and that includes five pauses and one crash (more on that below).

I built the tests first

How do you know a score is real? I didn’t want to find out AFTER four days of training that my test was broken. So I built the whole test suite first and tested the tests.

  • A model that knows nothing scored 25.2% on ARC-Easy. There are four answers to pick from, so that’s exactly what guessing should get.
  • GPT-2 scored 43.1% and 30.7% on my two tests. The published numbers are 43.8% and 32.6%, so my meters read about right.

Small tests before the big one

Four days is a long time to bet on a guess. So before the big run I trained a bunch of tiny 30M models, each one answering ONE question.

  • Which optimizer? I ran Muon and AdamW twice each. Muon won by 0.38 loss, and two runs of the same thing only differ by about 0.01. It also doubled the LAMBADA score (15% against 7.4%).
  • Can the tests be fooled? I trained one on text with the words scrambled. It scored 26.9% and 0%, which is guessing. Good!
  • Grow a small model, or start fresh? I grew a small model into a bigger one and its answers stayed the same (the biggest difference was 0.000002). Then a fresh one beat it anyway. So the big model started fresh.

The crash

About a third of the way in, the run died. My backup job had grabbed the save file at the exact moment the trainer tried to write it. The run picked itself back up from its last save at step 20,907, and I added a retry so that can’t kill it again.

Is it cheating?

If a test question is sitting in the training data, the score means nothing. So I searched the first 9.7 million training pages for any 13 words in a row that match a test question. That hit 31 of the 2,376 science questions and 1 of the 5,153 passages. I haven’t run that check on the second batch of data yet.

Where it is now

The reading stage is done. After that I started teaching it to hold a conversation, using a public chat dataset. The model stays on my PC, since this one is a personal research project (so there are no weights to download).
