Object-oriented programming

OOP is a way to organise code around things: a Dog, a BankAccount, a Shape. Each thing bundles its data with what it can do. Five ideas make it work. Build objects, call their methods, and watch what Python actually does behind each line.

    IdeaIn one lineEveryday version
    
            
              
    Class / objectA blueprint, and the real things built from itA cookie cutter and the cookies
    
              
    InheritanceA child class gets everything its parent hasEvery puppy is a dog, every dog is an animal
    
              
    PolymorphismOne call, the right behaviour for each kind of object"Speak!" gets a woof from a dog, a meow from a cat
    
              
    EncapsulationData locked inside, changed only through guarded methodsA cash machine: buttons outside, money locked inside
    
              
    AbstractionShow simple controls, hide the complicated partsA car: pedals and a wheel, not fuel injection timing
