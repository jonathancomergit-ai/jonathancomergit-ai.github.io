Async & the event loop

JavaScript can only do one thing at a time. So how does a page keep responding while it waits for timers, clicks and the network? Those wait outside, in queues, and the event loop feeds them in whenever the stack is free. Watch the code run in an order you might not expect.

The rules of the loop

              
    
                
  1. Run the script top to bottom. Anything that has to wait (timers, network, clicks) is handed to the browser.
    2. 
                
  2. When the call stack is empty, run every microtask (promise callbacks, await resumes).
    3. 
                
  3. Then run one task (a finished timer or a click), then go back to step 2.
    4. 
                
  4. A long loop keeps the stack busy, so nothing else runs. That's a frozen page.
