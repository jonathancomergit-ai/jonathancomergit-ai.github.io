Variables & references: names point at things

A variable isn't a box that holds a value. It's a name with an arrow pointing at an object. Two names can point at the same object, and that's behind the most common "why did that change?!" bugs. Watch the arrows, then build your own in the sandbox.

The rules

              
    
                
  1. a = something points the name a at an object. It never copies.
    2. 
                
  2. Changing an object (append, item = ...) is seen through every name that points at it.
    3. 
                
  3. Rebinding a name (a = new thing) only moves that one arrow.
    4. 
                
  4. Numbers and strings can't be changed, only rebound. Lists, dicts and objects can.
    5. 
                
  5. An object with no arrows pointing at it gets cleaned up (garbage collected).
