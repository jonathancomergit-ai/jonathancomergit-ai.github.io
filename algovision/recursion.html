Recursion: functions that call themselves

A recursive function solves a big problem by calling itself on a smaller one, until it hits a problem so small the answer is obvious (the base case). Every unfinished call waits on the call stack. Watch it pile up and unwind.

Every recursive function has two parts

        

          

            
1. A base case

            
The tiny version you can answer straight away. Without it the calls never stop.

            

          

          

            
2. A recursive case

            
Call yourself on a smaller input, so every call gets closer to the base case.

            

          

          

            
The stack remembers

            
Each waiting call keeps its own n on the stack. Too many at once and you get a stack overflow.

            

          

          

            
Memoization

            
Save each answer the first time. Next time, look it up instead of working it out again.
