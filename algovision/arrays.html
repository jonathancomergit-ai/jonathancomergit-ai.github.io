Arrays: cells in a row

An array is one solid block of memory split into equal-size cells. That one fact explains everything: why reading is instant, why inserting is slow, and why arrays sometimes have to pack up and move.

The cheat sheet

        
What each operation costs, and the reason in one line.

        

          

            
OperationBig OWhy

            
              
Read / write a[i]O(1)Address = start + i × 4. One calculation, no searching.

              
AppendO(1)*Drop it in the next empty cell. *Copies everything when full, but doubling makes that rare.

              
Insert / remove at iO(n)Everything after i has to shift over one cell.

              
Linear searchO(n)No idea where it is, so check cells one by one.

              
Binary searchO(log n)Sorted? Check the middle and throw away half, every time.
