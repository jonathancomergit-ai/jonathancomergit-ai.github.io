Scope & closures: which name means what?

Every function call gets its own box of names. To find a name, Python checks the nearest box, then the box around it, out to global. A closure is a function that keeps its box alive after the call ends, so it can remember things.

The rules

              
    
                
  1. Each call gets a fresh box of names. Assigning inside a function puts the name in its box.
    2. 
                
  2. To read a name: look in the current box, then the box the function was written in, out to global (LEGB).
    3. 
                
  3. If a function assigns a name anywhere, that name is local for the whole function. Use global / nonlocal to mean an outer one.
    4. 
                
  4. When a call ends its box goes, unless an inner function still needs it. That inner function is a closure.
